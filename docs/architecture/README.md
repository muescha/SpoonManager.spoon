# Architecture Documentation

The architecture documents are grouped by their role in the project:

- `reference/` contains general technical documentation that describes the current system and remains applicable as implementation details evolve.
- `completed/` contains completed architecture work that is still useful as a record of the implemented design.
- `planned/` contains concepts and features that are not implemented yet.
